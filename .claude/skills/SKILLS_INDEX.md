# Skills 技能库全景

---

## 技术栈速查（修正于 2026-09-17）

| 层              | 实际技术                                                                                      |
| -------------- | ----------------------------------------------------------------------------------------- |
| 后端             | Spring Boot + MyBatis-Plus + Sa-Token + Redisson + HikariCP，包名 `org.dromara.*`，框架版本 6.0.0 |
| 前端 (bell-plus) | Vue 3 + TypeScript + Vite + Pinia + **antdv-next** + **vxe-table** + vben-admin 封装        |
| 移动端 (UniApp)   | UniApp 3.x + Vue 3 + UView Plus                                                           |
| 架构             | Controller → Service → Mapper（三层，无 DAO 层）                                                 |

## 技能使用指南

### 1. 自动触发

通过 `skill-forced-eval.js` 钩子自动匹配：

```javascript
// 用户输入检测
if (input.includes('CRUD') || input.includes('增删改查')) {
  // 触发 crud-development 技能
}
```

### 2. 手动指定

在请求中明确技能名称：

```
请使用 vue-best-practices 技能开发用户列表页面
```

### 3. 组合使用

复杂任务可组合多个技能：

```
使用 crud-development + api-development + security-guard
开发完整的用户管理模块
```

## 新增技能开发流程

1. **确定技能分类**: 归属到合适的类别
2. **定义职责范围**: 明确技能解决的问题
3. **设置触发关键词**: 便于钩子自动匹配
4. **编写技能文档**: 使用标准模板
5. **测试触发机制**: 验证自动匹配效果
